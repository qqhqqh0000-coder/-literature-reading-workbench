# -literature-reading-workbench
读一篇论文，经常要同时做很多件事。  打开 PDF，复制摘要，翻译方法，查研究对象，记录主要结果，再把几个重要数字放进自己的表格。  遇到一段想保留的原文，还要记下它在哪一页。准备汇报时，又得重新找到那篇文章，确认当时记下的结论究竟来自哪里。  论文在一个文件夹，译文在聊天窗口，阅读笔记在表格里，自己的想法又写在另一份文档中。  几天后再回来，最费时间的往往是把这些内容重新对上。  所以，我做了一个 **文献阅读工作台**。  它是一个独立运行的 Windows 桌面文献阅读器，把 PDF、对照翻译、阅读笔记和阅读进度放在一起。读一篇，就逐渐留下一份能回看、能核对、能继续补充的记录。
